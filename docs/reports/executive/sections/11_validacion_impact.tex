La evidencia disponible muestra un GOP estable, mientras que se observa variación temporal del bitrate y una oscilación en la duración de partes HLS. La causa raíz de esta última observación aún no se considera demostrada. La comparación CBR OFF/ON se mantiene como prueba pendiente para aislar esa variable.
