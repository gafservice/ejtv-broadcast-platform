# 1. Objetivo

Esta baseline establece el estado oficial de la plataforma EJTV Broadcast Platform al finalizar la MISSION-015.

El objetivo de esta misión consistió en implementar, validar y documentar el servicio WebRTC sobre MediaMTX, integrándolo a la arquitectura multimedia existente sin afectar los servicios previamente validados.

# 11. Riesgos conocidos

No se identifican riesgos críticos.

Las pruebas fueron realizadas dentro de una red LAN utilizando conectividad directa.

Para despliegues sobre Internet podrán incorporarse posteriormente:

- Servidores STUN.
- Servidores TURN.
- Certificados TLS públicos.
- Balanceo de carga.

Estos elementos no forman parte del alcance de la MISSION-015.
