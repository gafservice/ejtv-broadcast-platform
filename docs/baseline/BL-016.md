# Validaciones completadas

Se verificó correctamente:

- funcionamiento individual de todos los protocolos;
- publicación de un flujo multimedia único;
- redistribución mediante MediaMTX;
- interoperabilidad entre protocolos;
- operación simultánea;
- estabilidad operativa;
- consumo de recursos;
- disponibilidad continua de servicios.

# Configuración validada

MediaMTX

- versión 1.19.2;
- ejecución mediante systemd;
- configuración ubicada en `/opt/ejtv/mediamtx/config/mediamtx.yml`.

FFmpeg

- versión 6.1.1;
- publicación RTSP;
- codificación H.264;
- codificación H.265 (escenario complementario);
- audio Opus;
- audio AAC.

HLS

- operación Low-Latency HLS confirmada.

WebRTC

- conexión establecida correctamente;

HEVC
