## Observaciones

Durante la validación del servicio HLS se comprobó que MediaMTX v1.19.0 implementa un mecanismo interno de administración de sesiones para Low-Latency HLS (LL-HLS), utilizando cookies HTTP durante el proceso de reproducción.

Debido a este comportamiento, las pruebas funcionales del servicio deben realizarse utilizando clientes HLS compatibles, como VLC o navegadores web modernos, los cuales administran automáticamente el proceso completo de negociación de la sesión.

La validación realizada durante esta misión confirmó la correcta generación del archivo `index.m3u8`, la creación dinámica de las listas de reproducción asociadas y la reproducción satisfactoria del flujo desde clientes HLS estándar, quedando oficialmente validada la integración del servicio HLS dentro de la plataforma EJTV Broadcast Platform.

Para una descripción detallada del procedimiento de validación y del comportamiento observado durante las pruebas, consultar el documento:

`docs/services/hls.md`
