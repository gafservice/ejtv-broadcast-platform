# BASELINE-017

# Línea Base de la Plataforma

**Misión:** MISSION-017

**Versión:** 1.0

**Estado:** Aprobada

**Fecha:** Julio 2026

---

# 1. Objetivo

La presente línea base establece el estado oficial de la plataforma **EJTV Broadcast Platform** al finalizar la **MISSION-017**.

Este documento constituye el punto de referencia para las futuras etapas de desarrollo y permitirá verificar que las siguientes misiones no comprometan la arquitectura, funcionalidad o documentación previamente aprobadas.

---

# 2. Estado General

Al cierre de la misión la plataforma se encuentra dividida en dos grandes componentes.

```text
EJTV Broadcast Platform

├── Plataforma Multimedia
│
└── EJTV Control Center
```

La plataforma multimedia permanece completamente operativa.

El Control Center dispone ahora de una arquitectura funcional completamente documentada.

---

# 7. Arquitectura

Se adopta oficialmente una arquitectura basada en capas.

```text
Frontend

↓

REST API

↓

Backend

↓

Adaptadores

↓

Infraestructura
```

Todo acceso a MediaMTX, FFmpeg y Linux deberá realizarse exclusivamente mediante el Backend.

---

# 8. Principios Arquitectónicos

Quedan oficialmente establecidos los siguientes principios.

- separación Frontend / Backend;
- API única;
- desacoplamiento mediante adaptadores;
- orientación al dominio;
- seguridad desde el diseño;
- escalabilidad;
- trazabilidad;
- modularidad.

# 16. Restricciones

A partir de esta línea base:

No deberán realizarse cambios estructurales sin:

- actualización documental;
- modificación del CHANGELOG;
- revisión de la arquitectura;
- generación del ADR correspondiente cuando aplique.

---

# 17. Riesgos Identificados

Los principales riesgos para las siguientes misiones son:

- desviación respecto a la arquitectura aprobada;
- duplicación de lógica entre Frontend y Backend;
- acoplamiento con MediaMTX;
- crecimiento desordenado del dominio;
- modificaciones sin documentación.

# 19. Estado Final

Al cierre de la **MISSION-017** la plataforma EJTV Broadcast Platform dispone de una arquitectura completamente documentada para el desarrollo del Control Center.

La infraestructura multimedia continúa operativa y validada, mientras que el nuevo componente de administración cuenta con una base técnica sólida que permitirá iniciar la implementación de software en las siguientes misiones.

Esta línea base se declara como la referencia oficial para todas las actividades de desarrollo posteriores.
