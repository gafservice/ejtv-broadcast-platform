# Introducción

Al finalizar una misión resulta necesario registrar el estado alcanzado
por el proyecto.

Este registro recibe el nombre de **Baseline** y constituye el punto de
referencia oficial para las siguientes etapas de desarrollo.

El Baseline representa una fotografía técnica del proyecto en un momento
determinado y permite conocer exactamente qué capacidades se encuentran
disponibles y cuáles serán desarrolladas posteriormente.

---

# Objetivo

El objetivo del Baseline consiste en establecer el estado oficial del
proyecto al finalizar la MISSION-000.

Este documento servirá como referencia para medir la evolución del
EJTV Broadcast Platform durante las misiones posteriores.

---

# Estado general del proyecto

Al concluir la MISSION-000 el proyecto dispone de una base metodológica
completa y de una estructura preparada para iniciar el desarrollo de
capacidades funcionales.

Durante esta etapa no se desarrollaron funciones orientadas al usuario.

El trabajo estuvo enfocado en construir los fundamentos técnicos y
organizacionales del proyecto.

---

# Arquitectura

Se encuentra definida la arquitectura base de la plataforma.

Las capas principales del sistema han sido establecidas y documentadas.

- Services
- Domain
- Adapters
- Infrastructure

La regla oficial de dependencias ha quedado definida y documentada.
