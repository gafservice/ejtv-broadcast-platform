# Engineering NOC

Este directorio contiene la documentación rectora de las capacidades permanentes
del Engineering NOC implementado por `control-center/`.

## Principio de separación

```text
control-center/backend/           implementación del backend y dominio
control-center/frontend/          interfaz de usuario
control-center/tests/             pruebas de la aplicación
control-center/docs/engineering/  planificación, arquitectura y evolución del NOC
```

La documentación general de la plataforma Broadcast permanece en `docs/`.
