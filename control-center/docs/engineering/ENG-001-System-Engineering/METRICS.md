# ENG-001 — Métricas

Cada métrica deberá definir:

| Campo | Descripción |
|---|---|
| Nombre | Identificador estable |
| Unidad | Unidad de medida |
| Fuente | Origen del dato |
| Frecuencia | Intervalo de recolección |
| Tipo | Gauge, counter, rate o estado |
| Etiquetas | Dimensiones |
| Retención | Tiempo de conservación |
| Umbrales | Warning y Critical |
