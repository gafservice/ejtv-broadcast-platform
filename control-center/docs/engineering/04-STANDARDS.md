# Engineering NOC — Estándares

## Documentación

Cada módulo deberá mantener:

- `README.md`
- `ROADMAP.md`
- `ARCHITECTURE.md`
- `METRICS.md`
- `DASHBOARD.md`
- `ALERTS.md`
- `TESTS.md`
- `CHANGELOG.md`
- `sprints/`

## Sprint

Cada sprint deberá contener:

```text
01-README.md
02-OBJECTIVE.md
03-PROBLEM.md
04-DESIGN.md
05-IMPLEMENTATION.md
06-TESTS.md
07-EVIDENCE.md
08-CHANGELOG.md
```

## Criterio de finalización

Una capacidad se considera completada únicamente cuando:

1. utiliza una fuente real;
2. posee semántica documentada;
3. maneja errores;
4. posee pruebas;
5. presenta evidencia reproducible;
6. actualiza roadmap y changelog.
