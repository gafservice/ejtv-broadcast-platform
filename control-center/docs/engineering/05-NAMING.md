# Engineering NOC — Convenciones de nombres

## Módulos

```text
ENG-NNN-Nombre-Descriptivo
```

Ejemplo:

```text
ENG-001-System-Engineering
```

## Sprints

```text
SPRINT-NNN-Nombre-Descriptivo
```

Ejemplo:

```text
SPRINT-001-CPU
```

## Métricas

```text
<dominio>.<recurso>.<medida>
```

Ejemplos:

```text
system.cpu.usage_percent
network.interface.rx_bytes_total
streaming.path.readers
```

## Alarmas

```text
ALM-<MODULO>-NNN
```

Ejemplo:

```text
ALM-ENG001-001
```
